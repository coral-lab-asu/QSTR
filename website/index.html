A

Question-conditioned structure

Target columns and key metadata are supplied. The challenge is to identify which events belong in the rows and compute their values—not discover a schema from scratch.

B

Executable reference answers

SQL over intermediate event tables supports construction and validation. At evaluation time, models must answer from commentary without that database.

C

Diagnosis beyond exact match

Primary-key recovery, aligned cell accuracy, numeric error, and counting bias distinguish finding the right entities from computing the right answer.

02 / Research findings

Right rows.
Wrong numbers.

Structured-looking outputs can hide substantial reasoning errors. Factorized evaluation makes the gap visible.

Recovering entities is not

Finding 02

Reason locally.
Compute more faithfully.

RowCoT yields the best cell accuracy among tested strategies for both open-weight models: 38.98% for Llama and 36.63% for Qwen. More calls or more tokens alone do not reliably improve values.

RowCoT is not the universal winner: other methods lead on exact match, and Qwen's lowest RMSE comes from Zero-Shot CoT.§6 · Table 3 ↗
Finding 03

Execution is a
persistent bottleneck.

Matched high-versus-low execution pressure increases weighted RMSE by 29.9 for Llama and 43.7 for Qwen. The direction survives balanced resampling.

Observational, matched contrasts—not causal interventions. Numeric metrics are conditional on evaluable outputs.§7.5 · Appendix E ↗
Finding 04

Bigger answers.
More undercounting.

At high output pressure, net counting bias turns negative: −7.1 points for Llama and −24.9 for Qwen. Correct row identities can still conceal omitted numeric contributions.

Net bias = overcount percentage − undercount percentage, measured on aligned, evaluable numeric outputs.§7.5 · Appendix F ↗

04 / Behind the benchmark

Built with execution.
Evaluated from text.

The manuscript's construction process links analytical intent to executable reference answers. The released CMT2 pipeline provides generation, SQL validation, and deduplication workflows.

  1. 01

    Ground

    Convert ball-by-ball narratives into intermediate event tables.

  2. 02

    Generate

    Expand human-authored seeds into grounded question–SQL candidates.

  3. 03

    Validate

    Execute SQL, filter candidates, deduplicate, and check question–program consistency.

  4. 04

    Diagnose

    Evaluate generated tables separately for row recovery and value fidelity.

Manuscript §4 reports a 400-question human audit with 97.2% question–SQL semantic coherence. This is not a claim that every released record is error-free.

Research scope & release availability

Q-STR is a cricket-domain diagnostic, not evidence of generalization to other narrative domains. The controlled set uses five matches. Construction is model-assisted; there is no executable code-generation baseline in these experiments.

The manuscript reports 620 source matches; the repository contains 638 CSV files. These counts have not been reconciled and should not be treated as interchangeable. The controlled split of 3,467 examples was not located among tracked release artifacts during this site review; its statistics and findings here are manuscript-reported, not a claim of download availability.

Historical ground truth contains unresolved records and answer mismatches. Current preparation filters invalid records and records exclusions. A newly prepared subset does not establish reproduction of the paper's scores. Upstream source attribution and data-license details remain gaps documented in the data card.
